## Design Specificity Verdict

Coherent incumbent world ("Lab Notebook" neobrutalism) — cream bench, ink borders, signal colors, Baloo 2 + Be Vietnam Pro. Not interchangeable with generic SaaS. Deterministic scan: 48 findings over `src/` (42 advisory micro-font-size, 6 warnings: 2× layout-transition on timer bars, 1× bounce-easing `animate-bounce`, 1× gray-on-color `text-gray-400 on bg-red-100` in WorkspaceHeader, 2× Arial fabric font outside DESIGN.md). No purple gradients, no glass, no nested-card epidemics — the system is disciplined.

## Priority Issues

- **[P1] Setup cognitive overload**: source toggle + folder list + 3 config cards + workspace checkboxes + CTA all visible. Fix: stepper + progressive disclosure (`distill`, `onboard`).
- **[P1] Quiz feedback legibility**: `truncate` hides long Vietnamese answers; dots 10px, no text alt. Fix: wrap answers, ≥24px markers + text (`layout`, `typeset`).
- **[P1] Contrast unverified**: white on `nb-blue`/`nb-red`, gray on accent (1 detector hit). Fix: measure + adjust (`colorize`, `audit`).
- **[P2] Motion debt**: timer `width` transition + `animate-bounce` + `shake` only; no reduced-motion path. Fix: transform-based timer, 150ms press grammar (`animate`, `optimize`).
- **[P2] Destructive flows are native**: `alert`/`confirm` in folder load, workspace close/delete, LamDe folder empty. Fix: inline nb-card errors + undo (`harden`).
- **[P2] Mobile adaptation**: NavBar 3 links crowd 360px; LamDe `w-64`/`w-72` rails + Workspace 3-pane have no collapse; 28px icon buttons < 44px. Fix: drawers + thumb-zone toolbars (`adapt`).
- **[P3] Type ramp drift**: 42× `text-[10px]`/`text-[11px]` micro-labels below the 12px label floor; Arial in canvas text. Fix: lift to 12px floor, map fabric text to Be Vietnam Pro (`typeset`, `polish`).
